# AI Review Attribution

AI-generated review comments must identify both the generating agent and the
human reviewer responsible for sending or approving the comment.

## Required footer

- End every review comment generated by an agent with an attribution footer.
- Include `Comment created by: <agent name>` using the active adapter or agent
  identity, such as Codex, Cursor, Claude Code, Devin, Gemini CLI, Via, or the
  configured reviewer name.
- Include `Reviewed by: <user name>` when a human reviewer has approved or is
  submitting the comment. If the human reviewer is unknown, write
  `Reviewed by: <pending human reviewer>`.
- Include `Generated by AI.` in the footer so the comment cannot be mistaken for
  unaided human authorship.
- Do not invent agent or human names. Use a known session identity, ask, or use
  the pending placeholder.
