# Question lenses

Use the smallest lens that advances the decision. Do not recite this list to
the user.

- **Necessity**: What outcome is strictly required?
- **Constraint**: What must not change or fail?
- **Assumption**: What has to be true for this option to work?
- **Alternative**: What would be chosen if this option disappeared?
- **Reversibility**: What is costly or impossible to undo?
- **Pre-mortem**: If this failed, what would have caused it first?
- **Steelman**: What is the strongest argument against the preferred option?
- **Scope**: What is explicitly not being solved now?
- **Success**: What observable result would prove the choice worthwhile?
