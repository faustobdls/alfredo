# Prompt structure checklist

Apply only the parts that make the request more precise.

1. State the role when expertise or voice changes the outcome.
2. Put verified context, audience, and constraints before the request.
3. Express the goal as one observable sentence.
4. Specify output format, length, language, and tone when they matter.
5. Add examples only when format or style would otherwise have several valid
   interpretations.
6. Decompose complex work into explicit deliverables and acceptance criteria.
7. Use delimiters only when multiple inputs or outputs need clear separation.
8. End with the requested action and a concise success check.
